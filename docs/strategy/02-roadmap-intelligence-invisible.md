# ROADMAP DIGIY — INTELLIGENCE INVISIBLE (2026)

> Repères : Q1 = M+0 à M+3, Q2 = M+3 à M+6, Q3 = M+6 à M+9, Q4 = M+9 à M+12  
> Principe directeur : L’intelligence est dans le système, pas dans la bouche.

## Q1 2026 — FONDATIONS INTELLIGENTES

### Dashboard Territorial (DRIVER)
- Zones chaudes/froides (near-real-time)
- Recommandations d’optimisation de parcours
- Scoring de performance par zone géographique  
**Intelligence** : patterns de demande + historiques horaires + zones  
**Visible** : “Dans ta zone, la demande monte le week-end”

### Scoring Restaurant (RESTO)
- Positionnement prix vs marché local
- Alertes variations de demande
- Recommandations menu par période  
**Intelligence** : analyse comparative + saisonnalité  
**Visible** : “Tes prix sont 15% sous la moyenne locale”

### Prédiction Occupation (LOC)
- Prévisions taux de remplissage
- Prix optimaux suggérés
- Alertes événements zone  
**Intelligence** : historique + événementiel (météo en option plus tard)  
**Visible** : “Forte demande prévue ce week-end — ajuste tes tarifs”

## Q2 2026 — OPTIMISATION TERRITORIALE

### Matching Intelligent (JOBS)
- Scoring compétences/besoin
- Recommandations profils
- Alertes opportunités géo-pertinentes  
**Intelligence** : NLP léger + signaux comportementaux + géographie  
**Visible** : “Profil recherché cette semaine : serveur exp. Saly”

### Analytics Marché (MARKET)
- Tendances produits par région
- Gaps offre/demande
- Recommandations stock  
**Intelligence** : analyse transactionnelle + saisonnalité  
**Visible** : “Ces produits performent mieux dans ta zone”

## Q3 2026 — FORMATION PERSONNALISÉE

### Academy Adaptatif
- Parcours basés sur performance réelle
- Modules suggérés selon profil
- Progression mesurée  
**Intelligence** : learning analytics + signaux d’usage  
**Visible** : “Formation recommandée : Optimisation pricing”

### Alertes Proactives
- Risques détectés (baisse perf, concurrence)
- Opportunités identifiées
- Actions suggérées  
**Intelligence** : détection patterns + prédictif léger  
**Visible** : “⚠️ Attention : ta visibilité baisse — action suggérée”

## Q4 2026 — INTELLIGENCE COLLECTIVE

### Benchmarks Anonymisés
- Position vs pairs (même catégorie/zone)
- Best practices détectées
- Écarts de performance  
**Intelligence** : analyse comparative agrégée  
**Visible** : “Top performers utilisent ces stratégies”

### Simulation Scénarios
- Impact changements prix/offre
- Prévisions revenus
- Optimisation mix services  
**Intelligence** : modèles prédictifs + scénarios  
**Visible** : “Si tu changes ça : impact estimé +X%”

## ❌ CE QU’ON NE DÉVELOPPE PAS
- Chat IA généraliste
- Assistant virtuel conversationnel
- Bot “réponse à tes questions”
- Génération de contenu visible côté user
- Toute interface brandée “IA”

## ✅ CRITÈRE DE VALIDATION POUR CHAQUE FEATURE
1) Quel problème métier concret ?
2) Quelle décision ça aide à prendre ?
3) Quel impact mesurable (revenu / temps / qualité) ?

Jamais : “c’est cool techniquement”  
Toujours : “ça change quoi pour le pro ?”
